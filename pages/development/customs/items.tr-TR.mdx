# Özel Eşyalar
PNX üzerinde kendi özel eşyalarınızı oluşturabilirsiniz. Kullandığınız kaynak paketinde eşyanın dokularının tam olduğundan emin olun.

## Özel Eşya Kaydetme
Eşyalarınızı eklentiniz **yüklenirken** (enabled olmadan önce) kaydetmeniz önerilir.
Kaydetmek için aşağıdaki kodu kullanabilirsiniz:

```java
// Gerekli importlar
import cn.nukkit.registry.RegisterException;
import cn.nukkit.registry.Registries;

// Daha sonra, onLoad() fonksiyonunuzda
try {
    Registries.ITEM.registerCustomItem(this, MySword.class);
} catch (RegisterException e) {
    throw new RuntimeException(e);
}
```

## Eşya Tanımı (Sınıfınız)
Aşağıda minimum özel eşya tanımı örneği verilmiştir. Dilerseniz bunu daha fazla genişletebilirsiniz.

Silah Örneği:
```java
import cn.nukkit.item.Item;
import cn.nukkit.item.ItemDiamondSword;
import cn.nukkit.item.customitem.CustomItem;
import cn.nukkit.item.customitem.CustomItemDefinition;
import cn.nukkit.item.customitem.data.CreativeCategory;
import cn.nukkit.item.customitem.data.CreativeGroup;
import cn.nukkit.item.utils.ItemEnchantSlot;


public class MySword extends Item implements CustomItem {
    public MySword() {
        super("powernukkitx:test_sword");
    }

    @Override
    public CustomItemDefinition getDefinition() {
        return CustomItemDefinition
                .simpleBuilder(this)
                .creativeCategory(CreativeCategory.EQUIPMENT)
                .creativeGroup(CreativeGroup.SWORD)
                .texture("test_sword")
                .name("Sword")
                .allowOffHand(false)
                .handEquipped(true)
                .glint(true)
                .damage(30)
                .enchantable(ItemEnchantSlot.SWORD, 20)
                .durability(1000, 5, 30)
                .build();
    }

    @Override
    public int getTier() {
        return ItemDiamondSword.TIER_DIAMOND;
    }
}
```

Araç Örneği:
```java
import cn.nukkit.item.Item;
import cn.nukkit.item.ItemDiamondSword;
import cn.nukkit.item.customitem.CustomItem;
import cn.nukkit.item.customitem.CustomItemDefinition;
import cn.nukkit.item.customitem.data.CreativeCategory;
import cn.nukkit.item.customitem.data.CreativeGroup;
import cn.nukkit.item.utils.DiggerEntry;
import cn.nukkit.item.utils.ItemEnchantSlot;


public class MyTool extends Item implements CustomItem {
    public MyTool() {
        super("powernukkitx:test_tool");
    }

    @Override
    public CustomItemDefinition getDefinition() {
        return CustomItemDefinition
                .simpleBuilder(this)
                .creativeCategory(CreativeCategory.EQUIPMENT)
                .creativeGroup(CreativeGroup.PICKAXE)
                .texture("test_tool")
                .name("My Tool")
                .allowOffHand(false)
                .handEquipped(true)
                .glint(true)
                .enchantable(ItemEnchantSlot.PICKAXE, 20)
                .durability(1000, 5, 30)
                .digger(
                        DiggerEntry.block("minecraft:coal_ore", 2),
                        DiggerEntry.create().speed(6).addAllWooden(),
                        DiggerEntry.create().speed(5).addTags("'my_custom_tag'")
                    )
                .build();
    }

    @Override
    public int getTier() {
        return ItemDiamondPickaxe.TIER_DIAMOND;
    }
}
```

```java
import cn.nukkit.item.Item;

    @Override

                .creativeCategory(CreativeCategory.ITEMS)

    }
}
```
